# P1177 【模板】排序

## 题目描述

将读入的 $N$ 个数从小到大排序后输出。

## 输入格式

第一行为一个正整数 $N$。

第二行包含 $N$ 个空格隔开的正整数 $a_i$，为你需要进行排序的数。

## 输出格式

将给定的 $N$ 个数从小到大输出，数之间空格隔开。

## 输入输出样例 #1

### 输入 #1

```
5
4 2 4 5 1
```

### 输出 #1

```
1 2 4 4 5
```

## 说明/提示

对于 $20\%$ 的数据，有 $1 \leq N \leq 10^3$；

对于 $100\%$ 的数据，有 $1 \leq N \leq 10^5$，$1 \le a_i \le 10^9$。

### 解题思路

快排
三点优化
有序性检验
~~小数组优化~~

### CODE
```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int a[100010];

int choose_id(int left, int right) {
	int left_num = a[left];
	int right_num = a[right];
	int mid_num = a[(left+right)>>1];
	if(left_num >= min(right_num,mid_num) && left_num <= max(right_num,mid_num)) return left;
	if(right_num >= min(left_num,mid_num) && right_num <= max(left_num,mid_num)) return right;
	return (left+right)>>1;
}

int partition(int left, int right) {
	int tmp_id = choose_id(left,right);
	swap(a[left],a[tmp_id]);
	int i=left, j=right;
	while(i<j) {
		while(i<j&&a[j]>=a[left]) j--;
		while(i<j&&a[i]<=a[left]) i++;
		swap(a[i],a[j]);
	}
	swap(a[left],a[i]);
	return i;
}

void quick_sort(int left,int right) {
	if(left>=right) return;
	bool is_sorted = true;
	for(int i=left;i<right;i++) {
		if(a[i+1]<a[i]) {
			is_sorted = false;
			break;
		}
	}
	if(is_sorted) return;
	int id=partition(left, right);
	if(id-1>0) quick_sort(left,id-1);
	if(id+1<n) quick_sort(id+1,right);
}

int main() {
	cin>>n;
	for(int i=0;i<n;i++) cin>>a[i];
	quick_sort(0,n-1);
	for(int i=0;i<n;i++) cout<<a[i]<<" ";
	cout<<endl;
}
```
