# P1249 最大乘积

## 题目描述

一个正整数一般可以分为几个互不相同的自然数的和，如 $3=1+2$，$4=1+3$，$5=1+4=2+3$，$6=1+5=2+4$。

现在你的任务是将指定的正整数 $n$ 分解成若干个互不相同的自然数（也可以不分解，就是这个数字本身）的和，且使这些自然数的乘积最大。

## 输入格式

只有一个正整数 $n$，（$3 \leq n \leq 10000$）。

## 输出格式

第一行是分解方案，相邻的数之间用一个空格分开，并且按由小到大的顺序。

第二行是最大的乘积。

## 输入输出样例 #1

### 输入 #1

```
10

```

### 输出 #1

```
2 3 5
30
```

### 解题思路
贪心

分解条件：
1.从2开始构建连续步长为1递增数列，直到剩余数值不够添加数列
2.构建数列剩余的数值按数列大到小分


### CODE
```cpp
/*
 *  版本1
 */
#include <bits/stdc++.h>
using namespace std;

int len=1;
int num[300001],ans[300001];

void cal(int x) {
	int tmp[300001],borrow=0;
	for(int i=0;i<len;i++) {
		tmp[i]=(num[i]*x+borrow)%10;
		borrow=(num[i]*x+borrow)/10;
	}
	while(borrow) {
		tmp[len++]=borrow%10;
		borrow/=10;
	}
	for(int i=0;i<len;i++) num[i]=tmp[i];
}

int main() {
	int n;
	cin>>n;
	num[0]=1;
	int tmp=n,cnt=2,cl=0;
	while(1) {
		if(tmp-cnt>=0) {
			ans[cl++]=cnt;
			tmp-=cnt;
			cnt++;
		}
		else {
			int k=tmp/cl;
			for(int i=0;i<cl;i++) {
				ans[i]+=k;
			}
			k=tmp%cl;
			for(int i=cl-1;i>=0;i--) {
				if(k) {
					ans[i]++;
					k--;
				}
				else break;
			}
			break;
		}
	}
	for(int i=0;i<cl;i++) {
		cout<<ans[i]<<" ";
		cal(ans[i]);
	}
	cout<<endl;
	for(int i=len-1;i>=0;i--) {
		cout<<num[i];
	}
	cout<<endl;
}
```
