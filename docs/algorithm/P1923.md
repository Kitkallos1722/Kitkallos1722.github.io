# P1923 【深基9.例4】求第 k 小的数

## 题目描述

输入 $n$ 个数字 $a_i$，输出这些数字中第 $k$ 小的数。最小的数是第 $0$ 小。

请尽量不要使用 `nth_element` 来写本题，因为本题的重点在于练习分治算法。

## 输入格式

第一行有两个整数，分别表示 $n$ 和 $k$。

第二行有 $n$ 个整数，第 $i$ 个数表示 $a_i$。

## 输出格式

一个整数，表示第 $k$ 小的数。

## 输入输出样例 #1

### 输入 #1

```
5 1
4 3 2 1 5

```

### 输出 #1

```
2

```

## 说明/提示

对于 $100\%$ 的数据，$1\le a_i<{10}^9$，$1 \le n < 5\times 10^6$，且 $n$ 为奇数。


### 解题思路

快排

### CODE
```cpp
#include <bits/stdc++.h>
using namespace std;

int n,k;
int a[5000010];

int choose_id(int left, int right) {
	int left_num = a[left];
	int right_num = a[right];
	int mid_num = a[(left+right)>>1];
	if(left_num >= min(right_num,mid_num) && left_num <= max(right_num,mid_num)) return left;
	if(right_num >= min(left_num,mid_num) && right_num <= max(left_num,mid_num)) return right;
	return (left+right)>>1;
}

int partition(int left, int right) {
	int tmp_id = choose_id(left,right);
	swap(a[left],a[tmp_id]);
	int i=left,j=right;
	while(i<j) {
		while(i<j&&a[j]>=a[left]) j--;
		while(i<j&&a[i]<=a[left]) i++;
		swap(a[i],a[j]);
	}
	swap(a[i],a[left]);
	return i;
}

int f(int left, int right, int k) {
	if(left>=right) return left; 
	bool is_sorted=true;
	for(int i=left;i<right-1;i++) {
		if(a[i+1]<a[i]) {
			is_sorted=false;break;
		}
	}
	if(is_sorted) {
		return left+k-1;
	}
	int id = partition(left,right);
	int len = id-left+1;
	if(len==k) return id;
	else if(len<k) {
		return f(id+1,right,k-len);
	}
	else {
		return f(left,id-1,k);
	}
}

int main() {
	cin.tie(nullptr);
    ios::sync_with_stdio(false);
	cin>>n>>k;
	for(int i=0;i<n;i++) cin>>a[i];
	int id = f(0,n-1,k+1);
	cout<<a[id]<<endl;
}
```
