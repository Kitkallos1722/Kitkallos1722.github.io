# P1591 阶乘数码

## 题目描述

求 $n!$ 中某个数码出现的次数。

## 输入格式

第一行为 $t(t \leq 10)$，表示数据组数。接下来 $t$ 行，每行一个正整数 $n(n \leq 1000)$ 和数码 $a$。

## 输出格式

对于每组数据，输出一个整数，表示 $n!$ 中 $a$ 出现的次数。

## 输入输出样例 #1

### 输入 #1

```
2
5 2
7 0
```

### 输出 #1

```
1
2
```

### 解题思路
模拟乘法。

需注意进位的数值会超过2位。可在最后统一处理。

$1000^{1000} = {10^{3}}^{1000} = 10^{3000}$

所以大概需要长度为3000的数组。
### CODE
```cpp
#include <bits/stdc++.h>
using namespace std;

int len=0;
int num[3001];

void cal(int x) {
	int borrow=0;
	int tmp[3001];
	for(int i=0;i<len;i++) {
		tmp[i]=(num[i]*x+borrow)%10;
		borrow=(num[i]*x+borrow)/10;
	}
	while(borrow) {
		tmp[len++]=borrow%10;
		borrow=borrow/10;
	}
	for(int i=0;i<len;i++) {
		num[i]=tmp[i];
	}
} 

int main() {
	int t;cin>>t;
	int n,a;
	while(t--) {
		cin>>n>>a;
		memset(num,0,sizeof(num));
		num[0]=1;len=1;
		for(int i=2;i<=n;i++) {
			cal(i);
		}
		int ans=0;
		for(int i=0;i<len;i++) {
			if(num[i]==a) {
				ans++;
			}
		}
		cout<<ans<<endl;
	}

}
```
