# P1601 高精度加法

## 题目背景

本题是高精度加法的模板题。

## 题目描述

给定两个非负整数 $a,b$，求它们的和。**不用考虑负数**。

## 输入格式

输入共两行，每行一个非负整数，分别为 $a,b$。

## 输出格式

输出一行一个非负整数，表示 $a+b$ 的值。

## 输入输出样例 #1

### 输入 #1

```
1
1
```

### 输出 #1

```
2
```

## 输入输出样例 #2

### 输入 #2

```
1001
9099
```

### 输出 #2

```
10100
```

## 说明/提示

对于 $20\%$ 的测试数据，$a,b \le 10^9$；  
对于 $40\%$ 的测试数据，$a,b \le 10^{18}$；  
对于 $100\%$ 的测试数据，$0\le a,b \le 10^{500}$。


### 解题思路

高精度加法

### CODE
```cpp
#include <bits/stdc++.h>
using namespace std;

string a,b;

string add(string a,string b) {
	reverse(a.begin(),a.end());
	reverse(b.begin(),b.end());
	string ret="";
	int temp=0;
	if(a.length()<b.length()) swap(a,b);
	while(b.length()<a.length()) b.push_back('0');
	for(int i=0;i<a.length();i++) {
		ret.push_back( (temp+a[i]+b[i]-2*'0')%10+'0' );
		temp=(temp+a[i]+b[i]-2*'0')/10;
	}
	if(temp) ret.push_back('1');
    reverse(ret.begin(),ret.end());
	return ret;
}

int main() {
	cin>>a>>b;
	string ans = add(a,b);
	reverse(ans.begin(),ans.end());
	cout<<ans<<endl;
}
```
